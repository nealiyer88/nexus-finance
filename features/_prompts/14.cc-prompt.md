## CONVENTIONS

**Python / naming:** snake_case functions, PascalCase classes, UPPER_CASE constants. Python 3.10+.

**Store layer (`core/graph/entity_store.py`):**
- Module-level `def`, no classes. Every new read takes `conn: sqlite3.Connection` as its FIRST argument and `tenant_id: Optional[str] = None` as its LAST.
- When `tenant_id` is `None`, apply **no** WHERE filter (V1 single-tenant SQLite default; `canonical_entities.tenant_id` is nullable). When set, filter on `canonical_entities.tenant_id`, joining child tables (`entity_aliases`, `system_references`, `entity_edges`) back to the canonical row — the child tables carry no `tenant_id` column of their own.
- **Do NOT import `rapidfuzz` in `core/graph/entity_store.py`.** A shipped test (`tests/test_blocking.py:425-436`) asserts neither `import rapidfuzz` nor `from rapidfuzz` appears in that file. The store supplies raw rows only; RapidFuzz scoring lives in the router layer or a new module.

**API layer (`api/`):**
- Obtain the SQLite connection **exclusively** via `core.matching.pending_store.get_connection`. Never call `sqlite3.connect` inside `api/`, and never `import sqlite3` in a dashboard page.
- Read the tenant as `tenant_id = request.state.tenant_id`, exactly as `api/routers/approvals.py` does. Never parse the header or an env var in the router.
- No bare UUID literals anywhere in `api/`, `dashboard/`, or `tests/` — a shipped guard test forbids them. Import `DEFAULT_TENANT_ID` from `api.middleware.tenant`; generate any second tenant with `uuid.uuid4()`.
